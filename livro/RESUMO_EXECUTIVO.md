### 2️⃣ CRÍTICO #2: Preencher Lacuna "XXXXXXXX"
```
⏱️  Tempo: 1 dia
📍 Localização: Capítulo 2.1 (seção apatridia)
❓ O que falta: Frase incompleta sobre imigrante
🎯 Ação: Localizar, ler contexto, preencher
✅ Concluído: [ ]
```

**Frase Atual:**
```

```

**O que fazer:**
1. Abra Word → Ctrl+F → busque "XXXXXXXX"

4. Releia para verificar coesão

### 3️⃣ CRÍTICO #3: Atualizar Data Roraima
```
⏱️  Tempo: 1 dia
📍 Localização: Capítulo 4.1
❓ O que falta: Data incerta com "(?)"
🎯 Ação: Confirmar ano, atualizar e corrigir digitação
✅ Concluído: [ ]
```

**Frase Atual:**
```
"atualmenteem 2022 (?) o Estado de Roraima estava..."
```

**O que fazer:**
1. Confirme: Dissertação foi em 2021, 2022 ou 2023?
2. Se 2022: retire o "(?)"
3. Separe "atualmenteem" em "atualmente em"
4. Ficará assim:
```
"Atualmente, em 2022, o Estado de Roraima estava..."
```

---

### 4️⃣ CRÍTICO #4: Adicionar Tradução *jus soli*
```
⏱️  Tempo: 1 dia
📍 Localização: Capítulo 2.1
❓ O que falta: Tradução de termo em latim
🎯 Ação: Adicionar tradução entre parênteses
✅ Concluído: [ ]
```

**Frase Atual:**
```
"adotou o princípio de *jus soli (tradução)*"
```

**O que fazer:**
1. Substitua "(tradução)" por "(direito de solo)"
2. Procure por outros termos em latim (jus, ratio, etc.)
3. Adicione tradução se houver
4. Ficará assim:
```
"adotou o princípio de *jus soli* (direito de solo)"
```
